# Mobile Formatting Toolbar

This example demos the opt-in **scroll container**: adding the `bn-scroll-container` class to the element wrapping your page content pins it to the visual viewport (using styles from BlockNote's stylesheet), so your content scrolls inside it and the toolbar stays perfectly in place while scrolling and zooming. Use the switch in the nav bar to toggle it off and compare.
