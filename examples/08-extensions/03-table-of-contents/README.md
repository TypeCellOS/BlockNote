# Table of Contents

This example shows an outline of the document's headings next to the editor, using `TableOfContentsExtension` and the `TableOfContents` component. The entry of the section being read is highlighted as the editor scrolls, and the outline follows edits to the headings.

**Try it out:** Scroll the document, click an entry to jump to its heading, or add a heading and see it appear in the outline.
