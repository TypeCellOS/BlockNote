# Toolbar Above Virtual Keyboard (Visual Viewport API)

This example renders a dummy formatting toolbar (a semi-transparent blue bar) that stays pinned just above the virtual keyboard, positioned using the [Visual Viewport API](https://developer.mozilla.org/en-US/docs/Web/API/Visual_Viewport_API). It's meant to demonstrate the known Android gap between the toolbar and the keyboard, caused by bottom browser UI shrinking the visual viewport.

**Try it out:** On a mobile device, focus the editor to open the virtual keyboard and watch the blue bar reposition above it.
