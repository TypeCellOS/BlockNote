# Collaborative Editing with YHub

This example uses [YHub](https://github.com/yjs/yhub) and Yjs v14 to sync a BlockNote document and share user cursors over WebSocket. It connects to a public demo server, so don't enter private information.

**Try it out:** Open this page in another browser tab or window to edit the same document together.
